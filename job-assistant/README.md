# Job Assistant

Lean personal job-search assistant.

## Goals
- ingest jobs
- score against profile
- tailor resume/answers
- queue applications
- optionally run local Playwright autofill

## Stack
- Next.js app
- AWS Lambda-style route handlers (scaffolded in app/api)
- DynamoDB schema docs
- S3 artifact strategy
- local Playwright worker for browser automation

## Status
Scaffolded MVP architecture and starter files.
